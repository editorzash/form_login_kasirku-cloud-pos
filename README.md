# Form Login — KASIRKU Cloud POS

Halaman portal autentikasi & login resmi untuk **KASIRKU** (Smart Cloud POS).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `admin@kasirku.id` (PIN: `888888`)
   - 💼 **Manajer Operasional**: `manager@kasirku.id` (PIN: `777777`)
   - 💳 **Kasir Shift**: `kasir1@kasirku.id` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Outlet Pusat (Kemang), Cabang Tebet, Cabang Bintaro).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../kasirku-cloud-pos/index.html`](../kasirku-cloud-pos/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
